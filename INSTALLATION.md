# Installation Guide

This guide explains how to install and run the Smart Classroom Automation System.

---

# 📋 Hardware Requirements

- Windows PC/Laptop
- Camera / Webcam / IP Camera
- ESP32
- Relay Module
- WiFi Connection

---

# 💻 Software Requirements

- Python 3.11
- VS Code (Optional)
