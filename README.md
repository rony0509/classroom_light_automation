# Smart Classroom Automation System

An AI-powered classroom automation system that uses Computer Vision, YOLOv8, MQTT, and ESP32 to detect human presence and automate classroom electrical systems.

---

# 🚀 Features

- Real-time human detection using YOLOv8
- CCTV/IP Camera support
- MQTT-based communication
- ESP32 relay automation
- Portable Python setup
- Low-resource optimization
- Multi-classroom scalable architecture

---

# 🧠 Project Overview

This project detects human presence inside classrooms using Computer Vision and automatically sends occupancy data to ESP32 devices through MQTT.

The ESP32 controls relays connected to classroom electrical systems such as lights or fans.

The goal of this project is to reduce unnecessary energy consumption and create a smart automation infrastructure.
